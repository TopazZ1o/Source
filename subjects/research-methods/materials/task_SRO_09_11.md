**Самостоятельная работа магистранта (СРС)**
**Дисциплина:** Методология и методы научных исследований

**Тема:** Сбор, подготовка и обеспечение качества исследовательских данных по теме магистерской диссертации

**Цель задания:** сформировать навыки определения потребности в исследовательских данных, обоснованного выбора источников и методов их сбора, разработки процедур предварительной обработки и обеспечения качества данных для проведения научного исследования.

## 1. Содержание задания

На основе утверждённой или предварительно выбранной темы магистерской диссертации необходимо разработать обоснованный план работы с исследовательскими данными.

**Задание 1.** Определение необходимых данных и источников их получения

1. Сформулировать цель исследования и определить, какие данные необходимы для её достижения.
2. Определить типы данных (количественные, качественные, структурированные, неструктурированные и др.).
3. Установить возможные источники получения данных (открытые наборы данных, базы данных, API, результаты экспериментов, журналы событий, результаты наблюдений и др.).
4. Оценить доступность, актуальность и пригодность выбранных источников для решения исследовательской задачи.

**Результат представить в таблице.**

| Необходимые данные | Источник получения | Тип и формат данных | Назначение в исследовании |
|---|---|---|---|
| | | | |
| | | | |

**Задание 2.** Обоснование методов сбора данных и критериев их отбора

1. Выбрать методы сбора данных, соответствующие цели и задачам исследования.
2. Обосновать выбранные методы с учётом их применимости, достоверности и воспроизводимости.
3. Определить критерии включения и исключения данных из исследовательской выборки.
4. Описать возможные ограничения и риски, связанные со сбором данных, включая вопросы конфиденциальности и соблюдения прав на использование данных.

**Результат представить в таблице.**

| Метод сбора данных | Обоснование выбора | Критерии отбора данных | Ограничения и риски |
|---|---|---|---|
| | | | |
| | | | |

**Задание 3.** Разработка плана предварительной обработки и обеспечения качества данных

1. Определить возможные проблемы качества данных: пропущенные значения, дубликаты, ошибки форматов, выбросы, несбалансированность выборки и др.
2. Предложить методы предварительной обработки: очистка, преобразование, нормализация, кодирование, интеграция данных и другие процедуры в зависимости от специфики исследования.
3. Определить критерии оценки качества данных: полнота, точность, согласованность, актуальность, уникальность.
4. Разработать последовательный план подготовки данных к дальнейшему анализу или моделированию.
5. Предусмотреть способы документирования изменений для обеспечения воспроизводимости исследования.

**Результат представить в таблице.**

## 2. Требования к выполнению

Работа должна быть непосредственно связана с темой магистерской диссертации и отражать специфику планируемого научного исследования.

Обязательные требования:

- Обоснованность выбора данных, источников и методов их сбора.
- Конкретность критериев отбора и оценки качества данных.
- Логическая последовательность этапов предварительной обработки.
- Указание реальных источников данных при их наличии. Если данные предполагается собрать самостоятельно, необходимо описать способ их получения.
- Соблюдение принципов академической честности, конфиденциальности и воспроизводимости исследования.

Форма представления: аналитический отчёт объёмом 4–6 страниц, включающий краткое описание исследования, три заполненные таблицы, необходимые пояснения и итоговый вывод.

В заключении необходимо обосновать, насколько предложенный подход к сбору и подготовке данных позволит получить достоверные результаты магистерского исследования.

## 4. Ожидаемый результат

По итогам выполнения самостоятельной работы магистрант должен представить план сбора, подготовки и обеспечения качества исследовательских данных, который может быть использован при разработке методологической части магистерской диссертации и организации последующего экспериментального исследования.

*Примечание:* На данном этапе не требуется обязательный сбор и программная обработка полного набора данных. Основное внимание уделяется методологическому обоснованию выбора источников, методов сбора, критериев отбора и процедур обеспечения качества данных. При наличии реального набора данных допускается демонстрация отдельных этапов его предварительной обработки.
