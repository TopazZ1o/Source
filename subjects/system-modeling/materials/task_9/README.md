**Выполнил:** Маханов Тимур

Материалы самостоятельной работы магистранта №9: отчёт, исходные файлы UML-моделей, изображения диаграмм и исходный код прототипа с результатами тестирования. ## Диаграммы

Файл `aircraft_maintenance_oo_model.drawio` открывается в diagrams.net (draw.io), одна диаграмма на странице.

| Страница | Диаграмма | Изображение | Рисунок в отчёте |

| 3 | Проектная модель классов: предметная область | `03_design_classes_domain.png` | 3 |

| 5 | Последовательность: записать ВС на обслуживание | `05_sequence_request.png` | 5 |
| 6 | Последовательность: назначить ресурсы | `06_sequence_assign.png` | 6 |
| 7 | Последовательность: допустить ВС к эксплуатации | `07_sequence_release.png` | 7 |
| 8 | Диаграмма деятельности | `08_activity.png` | 8 |
| 9 | Диаграмма состояний воздушного судна | `09_state_machine.png` | 9 |

Изображения и `.drawio` строятся из одного описания скриптами из `tools/` (`python tools/build_diagrams.py`, нужен Pillow), а не экспортом из diagrams.net, поэтому шрифты и положение подписей могут немного отличаться от экспорта. Линии в `.drawio` привязаны к фигурам там, где это задано в описании, текстовые подписи – отдельные элементы.

## Прототип

Язык Python 3.11, только стандартная библиотека. Пользовательского интерфейса и реальной базы данных нет: хранилище находится в памяти.

| Папка | Содержание | Проверок | Результат |
|---|---|---|---|
| `prototype/` | Базовая версия: заявки, назначение ресурсов, заказ-наряд, заключение и допуск, списание, контроль сроков, журнал | 28 | Все успешны |
| `prototype_v2/` | После изменения требований: очередь ожидания ресурсов (раздел 11 отчёта) | 36 (28 прежних и 8 новых) | Все успешны |

Запуск из папки `prototype` (или `prototype_v2`):

```
python demo.py
python -m unittest discover -s tests -t . -v
```

Вывод запуска тестов сохранён в `test_results.txt` каждой папки.
