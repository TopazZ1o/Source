**Выполнил:** Маханов Тимур
**Дисциплина:** «Анализ, моделирование и проектирование информационных систем»

Тема: «Моделирование и проектирование информационной системы управления запасами». Организация условная: склад запасных частей и материалов авиатехнической базы аэропорта (продолжение темы работы 9 – ИС ТО и ремонта самолётов). Работа учебная, данные искусственные.

## Состав

```
task_10/
├── README.md                          это описание
├── task_10.md                         текст отчёта (источник для docx)
├── Makhanov_T-AMDIS_task_10.docx      отчёт Word (25 страниц основной части, приложения А–Д)
├── Makhanov_T-AMDIS_task_10.pdf       отчёт PDF

├── data/                              модельный набор данных (24 позиции, спрос за 12 месяцев)
├── calc/                              gen_data.py, replenishment.py (ABC/XYZ, EOQ, ROP, имитация), make_diagrams.py, make_uml.py
├── results/                           результаты расчётов (csv, report.txt)

```

## Запуск

Расчёты (нужны numpy, matplotlib, Pillow), из папки `task_10`:

```
python calc/gen_data.py
python calc/replenishment.py
python calc/make_diagrams.py
```

Прототип (только стандартная библиотека), из папки `prototype`:

```
python demo.py
python -m unittest discover -s tests -t . -v
```

Вывод запуска сохранён в `prototype/demo_output.txt` и `prototype/test_results.txt` (24 проверки, все успешны).
