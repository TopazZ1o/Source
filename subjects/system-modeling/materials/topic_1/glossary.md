| ТО и Р | техническое обслуживание и ремонт | плановые и внеплановые работы по поддержанию самолёта в исправном состоянии |

## 2. Термины

| Термин | Что означает |
|---|---|
| Запас | запасные части и материалы, которые хранятся на складе для работ по ТО и Р |
| Запасная часть (деталь) | элемент самолёта, который устанавливают взамен снятого или изношенного |
| Расходный материал | то, что расходуется при работе: смазки, герметики, краски, крепёж |
| Ремонтопригодный агрегат | узел (насос, стартёр, блок управления), который после снятия можно отремонтировать и снова использовать |
| Деталь с ограниченным ресурсом | деталь, у которой задан срок службы (по времени, наработке или числу циклов); после исчерпания её нельзя ставить на самолёт |
| Ресурс обслуживания | специалист, оборудование или место в ангаре: назначается на заявку на время, а не расходуется (термин из твоих работ) |
| Ресурс детали | оставшийся срок службы детали. Не путать с ресурсом обслуживания: слово одно, смыслы разные |
| Наработка | сколько отработала деталь или самолёт (часы налёта, число полётов); данные берутся из системы учёта ВС авиакомпании |
| Срок годности | дата, после которой материал или деталь нельзя использовать, даже если ресурс не исчерпан |
| Заявка | запрос на плановое или внеплановое обслуживание самолёта |
| Заказ-наряд | документ на выполнение работ по заявке: этапы, исполнители, дефекты, использованные запчасти |
| Статус «Ожидает ресурсов» | статус заявки из твоей работы 9: нужный ресурс занят. Нехватка детали сюда пока не отнесена (раздел 8 отчёта) |
| Допуск ВС | разрешение на полёты после ТО; выдаёт руководитель или инспектор качества, если все условия выполнены |
| Номенклатура | перечень всех видов деталей и материалов, которые учитываются; у каждой позиции есть номер детали |
| Остаток | сколько единиц позиции лежит на складе |
| Резервирование | закрепление детали за конкретной заявкой или заказ-нарядом, чтобы её не выдали другому |
| Минимальный остаток, точка заказа | уровень запаса, при падении до которого нужно заказывать новую партию |
| Приёмка | приём поставки на склад с проверкой количества и документов |
| Входной контроль | проверка качества и документов поставленной детали или материала до помещения на склад |
| Документ о годности | документ, подтверждающий, что деталь пригодна к установке (происхождение, состояние); без него деталь не ставят |
| Партия | группа единиц, поступивших одной поставкой с общими данными (дата, срок годности, документ) |
| Серийный номер | уникальный номер одной конкретной детали, по нему прослеживается её история |
| Прослеживаемость | возможность по детали узнать, откуда она, на какой самолёт и когда установлена |
| Карантин | отдельная зона или статус для негодных и спорных деталей, откуда их нельзя выдавать |
| Статусы запаса | «годен», «карантин», «заблокирован», «списан»: выдавать можно только «годен» |
| Списание | окончательное снятие детали с учёта (брак, срок, исчерпанный ресурс) |
| Инвентаризация | сверка остатков в системе с фактическим наличием на складе |
| Кладовщик | работник склада: приём, выдача, возврат, инвентаризация |
| Специалист по запчастям | отвечает за нормы запаса и заявки на закупку |
| Граница автоматизации | что именно будет делать система, а что останется вне её (закупка, бухгалтерия) |
| Модуль | часть системы со своим набором функций, здесь – модуль учёта запасов |
| Проектная цель, показатель | измеримое требование к системе (например, «ответ не более 2 секунд»); числа в отчёте – предположения |
